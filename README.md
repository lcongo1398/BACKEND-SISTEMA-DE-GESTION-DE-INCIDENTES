# API - Sistema de Gestión de Incidentes (Help Desk)
## Actividad 8 - Desarrollo de Software

### 📋 Descripción
API REST desarrollada en **Java Spring Boot** con base de datos **PostgreSQL**, para la gestión de tickets de soporte técnico. Permite crear, consultar, actualizar y eliminar registros de incidentes.

### 🛠️ Tecnologías Utilizadas
- Lenguaje: Java 17
- Framework: Spring Boot 3.3.2
- Base de datos: PostgreSQL
- Herramienta de pruebas: Postman
- Despliegue: Render
